# Ontrack

OnTrack is a simple focus timer that keeps you on your goal.Set a task and a time,and OnTrack alerts you if you  leave the page.

Live demo:https://ontrack-kappa-ruby.vercel.app

## Features

-Set a task snd a timer in minutes or hours
-Beep sound when you leave the page
-Browser notification to bring you back
-Friendly AI-written reminder messages using your task and time left

## Built With

-HTML,CSS,Javascript(frontend)
-Node.js and Express(backend)
-Groq API(AI messages)
-vercel(frontend hosting)
-Render(backend hosting)

## Project Structure

-index.html and style.css:the page
-backend/server.js:the server that talks to Groq

##Note

The backend runs on a free plan,so the first AI message can take up to a minute to arrive.
